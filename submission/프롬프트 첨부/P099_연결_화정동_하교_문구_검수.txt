# 3단계 실행 프롬프트 · 화정동 하교 한국어 검수


목포대 통학버스로 광주 화정동에 돌아가는 학생을 기준으로, 하교 검색 결과와 송정③·송정⑦ 상세 화면의 한국어를 검수해줘. 학생이 화면을 읽고 세 질문에 답할 수 있게 해줘. 학교 어디에서 몇 시에 타지? 서광주우체국에서 내릴 정확한 위치도 확인됐나? 640m는 어디에서 어디까지 잰 거리일까? 정원 그린 디자인과 화면 구조를 유지하고, 이번 산출물은 검토용 문구 전후안으로 한정해.

1. 학생이 보는 순서로 원문을 뽑아줘. 로컬 시연에서 ‘유니버시아드힐스테이트2단지아파트’ 단지 본체를 골라. 요일 미선택 결과의 목적지 머리말 → 서광주우체국 카드 → 송정③·⑦ 상세와 복귀 순으로 읽고, 금요일을 선택했을 때 달라지는 문구도 확인해. 버튼과 제목, 위치·요일 주의, 지도와 출처를 펼쳤을 때 읽는 문구를 포함해. 반복되는 문구는 한 번만 싣고 쓰이는 위치를 적어. ChatGPT에서도 같은 맥락으로 검수할 수 있도록 ‘화면·상태 / 원문 / 바로 앞뒤에 보이는 말’을 담은 복사용 Markdown을 남겨줘. 실제 화면과 소스에서만 확인한 문구는 구분해.

2. 학생이 헷갈릴 만한 곳부터 고쳐줘. 결과 제목은 무엇이 나왔는지, 버튼은 누르면 무엇을 볼 수 있는지 드러나게 써줘. 짧은 라벨은 짧게 두고, ‘미확보·미제공·확인 필요’가 겹치는 안내는 무엇을 알고 무엇을 더 확인해야 하는지 일상적인 존댓말로 풀어줘. 이미 자연스러운 ‘학교 출발’, ‘금요일은 15:30’은 그대로 둘 수 있어. 공식 명칭과 시간표 원문 인용은 보존하고, 설명이 필요한 경우 주변 안내를 다듬어.

3. 바꾼 문장을 운행 자료와 대조해줘. MNU 스퀘어 앞은 사용자 확인을 근거로 한 학교 승차 위치야. 송정③의 학교 출발은 기본 17:30이고 금요일에는 15:30으로 바뀌어. 송정⑦은 18:20이야. 약 640m는 단지에서 등교 송정① ‘서광주우체국 건너편 CU편의점’ 지도 표시점까지의 직선거리야. 실제 하차 위치, 도보 거리, 하차 도착 시각, 당일 운행 여부를 문구로 확정하지 마. 자료끼리 맞지 않으면 어느 표현을 보류할지와 이유를 알려줘.

4. 문장별 차이와 화면 전체의 읽는 흐름을 함께 보여줘. 먼저 ‘화면·위치 | 현재 문구 | 제안 문구 | 학생에게 무엇이 명확해지는지’ 표를 작성해. 이어서 390px에서 보이는 순서대로 결과 카드와 두 편의 상세 요약을 문구 교체 전후로 나란히 보여줘. 같은 사실은 결과와 상세에서 같은 뜻으로 읽혀야 해. 긴 지명과 금요일 안내가 줄바꿈돼도 어느 편의 정보인지 살펴봐. 스크린리더로 편명 링크를 읽을 때도 지점명과 출발 시각이 맞는지 확인해. 실제 렌더링을 확인한 항목만 그렇게 표시해. 앱 반영은 다음 단계야.

로컬 시연 주소는 [화정동 하교](http://127.0.0.1:5173/?demo=hwajeong#/search)다. 화면·운행 정보 대조에는 [P098 실제 화면과 검증](../evidence/garden-app-20261112/REVIEW.md), [DESIGN.md](../design/DESIGN.md), [DATA_RULES.md](../context/DATA_RULES.md)를 참고해.
