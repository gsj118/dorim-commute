# 2단계 실행 프롬프트 · 정원 그린 디자인 시스템을 실제 앱에 적용하기


---

목포대학교 광주권 통학버스 프로젝트의 2단계를 진행해줘. 근거를 모아 만든 혼합 디자인 시스템을 문서화하고 현재 React 앱의 일반 이용 화면에 적용해. 정원 그린이 사용자가 선택한 최종 방향이야. 넓은 바탕은 따뜻한 중립색, 카드는 흰색으로 두고 초록은 주요 동작과 현재 선택에 집중해.

### 1. 적용 전 기준 잡기

AGENTS.md, `docs/design/DESIGN.md`의 ‘현재 색상 기준 · 정원 그린’, `docs/design/UX_FLOW.md`와 변경 대상 코드를 읽어. P087 시안에서 정보 배치를 가져오고 P097 추가 추출과 정원 시안 기준으로 색을 입혀. Dembrandt 실측값은 기존 JSON으로 대조하고 현재 앱의 같은 조건에서 적용 전 화면을 확보해.

### 2. 디자인 토큰을 실제 앱에 연결하기

DESIGN.md의 역할별 토큰을 기존 CSS 변수와 연결해. National Trust에서 추출한 초록 `#007A3B`은 검색·선택한 방향·편명 링크, 본문색 `#1F1F1F`은 정류장과 시각에 써. 따뜻한 바탕 `#F7F5EC`와 카드 `#FFFEFA`를 넓게 두고, 목적지 머리말 아래에만 잔디와 작은 꽃을 배치해. 잔디는 브루클린 식물원 연두 `#7AC142`, 풀 그늘과 꽃은 서울식물원 청록 `#229786`·노랑 `#FFF691`이야. 카드 번호는 연한 잎색 바탕에 짙은 글자로 읽히게 하고, 장식이 지명·시각을 밀어내거나 상태 표시처럼 보이지 않게 해. 직접 추출, 요소별 측정, 조정값은 `docs/evidence/garden-tokens-20261112/EXTRACTION.md`를 보고 구분해. 쇼케이스는 같은 폴더의 `garden-preview.html`을 참고해. GrepBoard의 파랑 `#0A5FB8`은 공식 외부 링크에 한정해. 거리 근거를 설명하는 일반 문장, 위치 미확인 안내, 키보드 초점은 각각 문서에 정한 보조·주의·초점 토큰을 써. 배경마다 실제 대비를 확인하고 링크와 선택 상태에는 텍스트·형태 단서도 줘. 아래에 언급한 편명·시각은 레이아웃 검증용이야.

### 3. 대표 화면부터 실제로 적용하기

- 화정동 하교 결과 — 지점명이 먼저 읽히고 그 아래 거리의 기준과 위치 확인 상태가 보이게 해. 각 편은 하나의 상세 링크 행으로 만들고 편명·학교 출발을 같은 열에 맞춰. 송정③ 기본 17:30 바로 아래에 ‘금요일은 15:30’, 다음 행에 송정⑦ 18:20이 와야 해. 이는 검증 사례이므로 실제 렌더링은 데이터 기반으로 구현해. 같은 승차 위치가 모든 결과에 공통일 때만 목록 위에 ‘학교 승차 MNU 스퀘어 앞 (사용자 확인)’을 한 번 표시해.
- 거리와 조건 — 화정동 단지 본체에서 약 640m는 등교 송정① ‘서광주우체국 건너편 CU편의점’ 표시점까지의 직선거리야. 지점의 실제 하차 위치, 당일 운행, 하차 도착 시각과 구분해. 같은 이름의 다른 지점, 편별 경유·요일 예외, 충돌·미확인 안내가 행을 줄이는 과정에서 사라지지 않게 해.
- 등교와 상세 — 등교 결과 열은 ‘지점 승차’로 표시해. 하교 상세는 학교 승차 위치·출발 시각을 함께 읽고 선택한 광주 하차 지점으로 이어지게 해. 기존 상세 URL, 정류장 경유 순서, 위치 설명·공식 출처와 목록 복귀를 살려줘. 홈·검색 조건·직접 노선 목록에서 같은 동작은 같은 색으로 연결해. As-is 비교 화면과 평가 절차는 기존 비교 기준을 유지해.
- 390px 레이아웃 — 바깥과 카드 안쪽 16px, 지점명 21px/28px, 시각 22px/28px, 기본·금요일 시각 간격 4px부터 적용해. 320px에서 긴 지명이나 여러 줄 조건이 생기면 행 높이가 늘어나게 해. 실제 앱의 지도 선택·더보기·출처 펼침·빈 결과 복구도 그대로 쓸 수 있어야 해.

### 4. 검증하고 결과 보여주기

타입검사·빌드·기존 단위/UI 시험과 변경 흐름의 브라우저 회귀를 실행해. 390px에서 화정동 단지 본체를 골라 두 편과 금요일 시각을 대조하고, 각 상세 진입·목록 복귀 후 초점과 펼침 상태, 더보기, 지도 번호 선택을 확인해. 등교 사례 하나와 결과 0건에서 전체 목록으로 돌아가는 흐름도 확인해. 320px 및 데스크톱에서 잘림·가로 넘침을 점검하고 실제 글자·배경·초점 대비를 측정해. 실행 중인 서버와 등록된 Kakao 설정을 재사용해.

완료하면 동일 장소·방향·요일·390px에서 촬영한 실제 앱의 적용 전후 화면을 나란히 보여줘. 동작하는 로컬 시연 링크, 갱신한 DESIGN.md, 검증 결과와 남은 판단도 함께 알려줘. 프로젝트 관례에 맞춰 요청·결정·증거를 기록하고, 자동 검사와 실제 사람의 사용성 평가는 구분해.
