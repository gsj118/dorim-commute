# 도림통학 검색 화면과 시연 목록 간소화

현재 도림통학 앱을 수정해 주세요. 대표 과업은 도림캠퍼스에서 광주 서구 화정동 유니버시아드 힐스테이트 2단지로 하교하는 것입니다. 시연과 일반 검색에 같은 동작을 적용하세요.

1. 화면 문구를 통학생이 지금 결정해야 하는 일에 맞춰 정리하세요. 노선 목록 상단의 ‘공식 PDF에 수록된 광주권 운행편을 방향별로 확인하세요’는 삭제하세요. ‘하교 시간표 전체 19편 중 19편…’ 같은 전체 자료 통계는 기존 ‘거리 비교에 쓴 위치 자료’ 안에 두세요. 결과 제목에는 현재 장소·조건의 후보 수와 정렬 기준만 짧게 표시하세요. 다른 검색 조건으로 넘어가며 시간 제한이 풀릴 때처럼 실제 결과가 달라지는 안내는 해당 동작 옆에 두세요.
2. 장소 검색은 일치도가 높은 3곳부터, 장소 선택 후에는 승하차 지점 카드 3곳부터, 전체 노선 목록은 운행편 5개부터 보여주세요. 결과가 더 있으면 ‘장소 더 보기’, ‘하차 지점 더 보기’, ‘운행편 더 보기’처럼 대상과 남은 수가 드러나는 버튼으로 같은 단위씩 추가하세요. 남은 결과가 없으면 버튼을 숨기세요. 기존 장소 페이지 이동과 더 보기는 하나의 흐름으로 통합하고, 단지 본체·정문·후문처럼 서로 다른 장소는 기존 순서와 이름을 보존하세요. 3·3·5는 이번 시연에서 검토할 초기값입니다.
3. 먼저 전체 결과에 검색·정렬·반경·시간 조건과 기존 최대 정류장 수를 적용한 뒤 보이는 개수만 나누세요. 지점 하나를 열면 그곳에서 비교할 편과 시각을 함께 볼 수 있어야 합니다. 학교 승차 위치와 공통 안내는 한 번만 쓰고, 금요일 대체 시각 등 편별 예외는 해당 편에 붙이세요. 등교 지점 승차 시각, 하교 학교 출발 시각, 참고 거리의 끝점과 실제 승하차 위치 미확인은 첫 카드에서 읽을 수 있게 하세요.
4. 상세에서 돌아오면 펼친 개수·선택·초점·스크롤을 복원하세요. 지도에서 접힌 지점을 선택하면 해당 카드까지 펼치고, 검색어·방향·조건이 바뀌면 새 결과의 첫 묶음부터 보여주세요. 거리 후보가 0개일 때에는 해당 조건에서 찾지 못했다는 짧은 설명과 조건 변경·전체 시간표 경로를 제공하세요. 시연 목적지와 평가 중 ‘시나리오 다시 보기’는 탐색 중 계속 접근할 수 있게 하세요.
5. 모바일 390px와 데스크톱에서 화정동 2단지 검색 → 단지 본체 선택 → 하차 후보 비교 → 더 보기로 추가한 카드의 상세 → 목록 복귀를 직접 확인하세요. 경계 개수, 마지막 항목, 숨겨진 지도 지점, 0건 복구, 키보드 더 보기도 점검하세요. 자동 시험 결과와 실제 화면에서 확인한 내용을 구분해 보고하세요.
