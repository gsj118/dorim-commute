# 도림통학

국립목포대학교 도림캠퍼스와 광주를 오가는 학생이 익숙한 장소 이름으로 통학편을 찾는 HCI 프로젝트입니다. 등교는 광주에서 탈 지점과 그곳의 승차 시각, 하교는 목적지 주변에서 내릴 지점과 학교에서 탈 곳·출발 시각을 보여 줍니다. 2026학년도 2학기 학교 노선표(안)의 광주권 등교 19편과 하교 19편을 담았습니다.

## 앱 실행

Node.js 24와 pnpm 11.25.0을 사용합니다. 저장소를 내려받고 프로젝트 폴더에서 아래 명령을 실행하세요. macOS 터미널과 Windows PowerShell에서 명령이 같습니다.

~~~sh
cd app
pnpm install --frozen-lockfile
pnpm dev
~~~

브라우저에서 [도림통학 홈](http://127.0.0.1:5173/) 또는 [금요일 화정동 하교 비교](http://127.0.0.1:5173/#/compare)를 여세요. 비교 화면에서 **운행편 예시 바로 보기**를 누르면 별도 키 없이 서광주우체국을 지나는 송정③의 금요일 학교 출발 시각과 승차 위치를 확인할 수 있습니다.

실제 장소 검색과 지도에는 Kakao Maps JavaScript 키가 필요합니다. 본인의 카카오 앱에서 지도 기능을 켜고 실행 주소 `http://127.0.0.1:5173`을 등록한 뒤, `app/.env.example`을 `app/.env.local`로 복사해 `VITE_KAKAO_MAP_JS_KEY`를 채우고 개발 서버를 다시 시작하세요. 키 없이도 시간표 목록, 운행편 상세, 비교 화면을 열 수 있습니다.

## 구현과 확인

React·TypeScript·Vite로 화면을 구성하고, 시간표·승하차 지점은 정적 데이터에서 읽습니다. 직선거리를 표시할 때는 어떤 지도 표시점이나 시설을 기준으로 쟀는지 함께 보여 줍니다. 실제 도로변 승하차 위치와 당일 운행 조건은 학교 안내를 확인하세요.

~~~sh
pnpm test
pnpm build
~~~

위 명령은 `app` 폴더에서 실행합니다. `pnpm build`는 타입 검사 후 배포용 파일을 만듭니다. 브라우저 검사 절차는 [프로덕션 테스트 안내](app/tests/production/README.md)에 있습니다.

공개용 첨부와 시간표에서는 학번과 휴대전화 번호를 가렸습니다. Unibus 캡처에서는 화면 위쪽의 브라우저 탭과 프로필을 잘라냈습니다.
